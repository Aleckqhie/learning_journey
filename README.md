# Advanced Password Generator 🔐

A customizable command-line password generator with strength analysis and history tracking.

## Features
- Generate custom passwords with configurable options
- Password strength analyzer
- Exclude similar characters (l, 1, I, O, 0)
- Password generation history
- Quick strong password generation

## Installation
```bash
git clone https://github.com/Aleckqhie/learning_journey.git
cd password-generator
python password_generator.py
```

## Usage
Run the program:
```bash
python password_generator.py
```

Follow the interactive menu to:
1. Generate custom passwords
2. Generate quick strong passwords (16 characters)
3. View password history
4. Exit

## Requirements
- Python 3
- No external dependencies (uses standard library only)
